Privacy Policy

Last updated: February 2026

1. Introduction

This Privacy Policy explains how this application (“VeloMap”) handles user information.
We respect your privacy and are committed to protecting it.

2. Information We Collect

VeloMap does not collect, store, or share any personal data.

The only information used by VeloMap is device location, which is required solely to display the user’s current position on the map and show routes correctly.

Location data is used in real time

Location data is not stored

Location data is not transmitted to any server

Location data is not shared with third parties

3. How We Use Information

Location information is used exclusively for the following purpose:

Displaying the user’s current position on the map

Showing routes relative to the user’s location

VeloMap does not use location data for tracking, analytics, advertising, or profiling.

4. Data Sharing

VeloMap does not share any data with third parties.

No information is sent to external servers, analytics services, advertisers, or other organizations.

5. Data Storage and Security

VeloMap does not store any personal or location data.

All location processing happens locally on the user’s device.

6. User Control

You can control or disable location access at any time through your device settings.
If location permission is denied, VeloMap may not be able to display your position on the map.

7. Children’s Privacy

VeloMap does not collect any personal information from users of any age, including children under 13.

8. Changes to This Privacy Policy

If VeloMap’s functionality changes in a way that affects privacy, this Privacy Policy will be updated accordingly.
